# Retirement

> Effective: 2026-09-25
>
> Ming Capability Pack is retained as historical research/provenance and is no longer an active runtime/platform.

## Evidence for the decision

Issue #1 `Shrink Gate — prove what survives after external tools own execution` froze expansion and independently concluded:

- external hosts already own generic execution;
- Recipe did not reliably improve the tested real outcome;
- Acceptance language can survive as a thin human-readable checklist;
- resolver / registry / marketplace / executor / generic verifier do not earn continued Ming-specific implementation;
- the Capability Pack runtime/platform should be **REPLACE/RETIRE**.

## What may survive

Only after repeated real use proves value:

- portable Markdown / Agent Skill Recipe;
- portable Acceptance checklist / contract.

Destinations:

- project-specific asset → that Project Repo;
- cross-task YueMing-proven asset → `YuemingHub/agent-workspace`;
- public reusable asset → graduate later to a dedicated public repo/registry only if it remains valuable outside YueMing context.

## What does not migrate

Do not migrate merely because code exists:

- `ming_auto` runtime;
- capability resolver;
- marketplace/search/install machinery;
- generic workflow engine;
- generic verifier framework;
- evidence runtime;
- proprietary recipe platform.

External mature Agent / Skill / MCP / SaaS / tool ecosystems are the default execution source.

## Package status

The historical npm package may remain retrievable. This repository no longer promises active feature development or that the package represents YueMing's current Agent architecture.

Git history is the provenance archive.
